2ติดตั้งเครื่องมือ (Windows)

ทำครั้งเดียว ติดตั้งเฉพาะตัวที่จะใช้ก็ได้ หรือพิมพ์บอก Claude Code ว่า "ช่วยติดตั้ง FFmpeg, Python และ Node.js ให้หน่อย" ก็ได้เหมือนกัน

เครื่องมือใช้ทำอะไรคำสั่งติดตั้ง

3Workflow การผลิตวิดีโอทั้งหมด

ใช้ได้ทั้งคลิปสอน คลิปขายของ และคลิปโซเชียล ขั้นไหนที่ไม่ต้องใช้ข้ามไปได้เลย

วางแผน→สคริปต์→สตอรีบอร์ด→เตรียมไฟล์→เสียง→ประกอบภาพ→ซับ+เพลง→Export→ตรวจ
  1. วางแผน (Brief) · คุณ + Claude
    กำหนดเป้าหมาย กลุ่มผู้ชม แพลตฟอร์ม ความยาว และโทนของคลิป
    "ช่วยวางแผนคลิป TikTok 45 วิ แนะนำคอร์สออนไลน์ สำหรับครู โทนเป็นกันเอง"
  2. เขียนสคริปต์ · Claude
    ให้ Claude เขียนบทพูดแยกเป็นฉาก พร้อมเวลาของแต่ละฉาก 3 วินาทีแรกต้องดึงความสนใจ (hook) ให้ได้
  3. สตอรีบอร์ด / Shot list · Claude
    ทำตารางแต่ละฉาก ระบุภาพที่เห็น ข้อความบนจอ เสียง และระยะเวลา ให้บันทึกเป็นไฟล์ storyboard.md
  4. เตรียมไฟล์ (Assets) · คุณ
    รวมคลิปดิบ รูป โลโก้ เพลง และฟอนต์ไว้ในโฟลเดอร์เดียว เช่น assets/
  5. ทำเสียงพากย์ · Claude + edge-tts
    แปลงสคริปต์เป็นไฟล์เสียง ความยาวของเสียงจะเป็นตัวกำหนดความยาวของแต่ละฉาก
  6. ประกอบภาพ · Claude + FFmpeg/Remotion
    ตัดต่อคลิปหรือสร้างภาพเคลื่อนไหวตามสตอรีบอร์ด ให้ render ตัวอย่างสั้นๆ (preview) ก่อนเสมอ
  7. ใส่ซับ เพลง และเสียงประกอบ · Claude
    ฝังซับไทย ปรับเพลงให้เบากว่าเสียงพูด และใส่ fade-in / fade-out
  8. Export · Claude
    render ไฟล์สุดท้ายตามขนาดของแพลตฟอร์ม (ดูข้อ 11)
  9. ตรวจสอบ (QA) · คุณ
    ดูคลิปจริงทั้งคลิป ตรวจคำผิด เสียงตรงกับภาพไหม และฟอนต์แสดงผลถูกไหม แล้วบอก Claude ให้แก้เฉพาะจุดที่ผิด

4หลักการเขียน Prompt ให้ Claude Code

prompt ที่ดีควรตอบให้ได้ว่า "เอาไฟล์อะไร → ทำอะไร → ออกมาเป็นแบบไหน" ใช้สูตรนี้

เป้าหมาย ทำคลิปอะไร Input ไฟล์อยู่ไหน Output ขนาด/ความยาว/ชื่อไฟล์ สไตล์ โทน ฟอนต์ สี ข้อห้าม สิ่งที่ห้ามทำ ตรวจ ทำ preview ก่อน
📋 เทมเพลต Prompt (คัดลอกไปแก้ได้)
เป้าหมาย: ทำคลิป [ประเภทคลิป] เรื่อง [หัวข้อ] สำหรับ [แพลตฟอร์ม]
Input: ไฟล์อยู่ในโฟลเดอร์ [ชื่อโฟลเดอร์] ได้แก่ [รายการไฟล์]
Output: [ขนาด เช่น 1080x1920], ยาวประมาณ [X] วินาที, 30fps, บันทึกเป็น output/[ชื่อไฟล์].mp4
สไตล์: โทน [สนุก/ทางการ/มินิมอล], ฟอนต์ [Sarabun], สีหลัก [#xxxxxx]
ข้อห้าม: ห้ามเขียนทับไฟล์ต้นฉบับ
ขั้นตอน: ทำ preview 10 วินาทีให้ดูก่อน ถ้าผมโอเคค่อย render เต็ม
และช่วยเขียนเป็นสคริปต์ที่รันซ้ำได้ด้วย

✅ เคล็ดลับที่ช่วยได้มาก

ระบุตัวเลขชัดเจน

เขียนว่า "เพลงเบาลง 70%" หรือ "ช่วง 0:30–1:45" แทน "เพลงเบาๆ" หรือ "ช่วงกลางคลิป"

ทำทีละขั้น

สั่งงานใหญ่เป็นรอบเดียวมักพลาด ให้แบ่งเป็น สคริปต์ → เสียง → ภาพ → ซับ

ขอ preview เสมอ

render แค่ 5–10 วินาทีก่อน ประหยัดเวลามากเวลาต้องแก้

ขอให้ทำเป็นสคริปต์

เช่น make_video.py ครั้งหน้าแค่เปลี่ยนไฟล์แล้วรันใหม่

แก้แบบเจาะจง

"ซับฉากที่ 3 ขึ้นช้าไป 0.5 วิ" ดีกว่า "ซับไม่ตรง"

เก็บต้นฉบับไว้

ให้ไฟล์ผลลัพธ์อยู่ใน output/ แยกจาก assets/

❌ Prompt กว้างเกินไป✅ Prompt ที่ดี
ทำคลิปให้หน่อยทำคลิปแนวตั้ง 1080x1920 ยาว 30 วิ จากรูป 5 รูปใน assets/ รูปละ 6 วิ ซูมเข้าช้าๆ ใส่เพลง bg.mp3 แล้ว fade-out ตอนจบ
ใส่ซับถอดเสียงภาษาไทยจาก talk.mp4 ด้วย Whisper ทำเป็น .srt ให้ผมตรวจก่อน แล้วฝังซับฟอนต์ Sarabun ขนาด 22 ตัวขาวขอบดำ
ทำให้ไฟล์เล็กลงบีบ final.mp4 ให้เล็กกว่า 50MB โดยคงความละเอียด 1080p

5ตัดต่อคลิปด้วย FFmpeg

ไม่ต้องจำคำสั่งเอง แค่พิมพ์ prompt ทางซ้าย Claude จะเขียนคำสั่งทางขวาให้ ตารางนี้มีไว้ให้เห็นว่าเบื้องหลังเกิดอะไรขึ้น

Prompt ที่พิมพ์คำสั่งที่ Claude จะรัน (ประมาณนี้)
ตัด clip.mp4 ช่วง 0:30 ถึง 1:45ffmpeg -ss 00:00:30 -to 00:01:45 -i clip.mp4 -c copy cut.mp4
ต่อทุกคลิปในโฟลเดอร์เป็นคลิปเดียวสร้าง list.txt แล้วรัน ffmpeg -f concat -safe 0 -i list.txt -c copy merged.mp4
แปลงเป็นแนวตั้ง 9:16ffmpeg -i in.mp4 -vf "crop=ih*9/16:ih,scale=1080:1920" out.mp4
ใส่เพลงพื้นหลังเบาๆffmpeg -i video.mp4 -i bg.mp3 -filter_complex "[1:a]volume=0.3[bg];[0:a][bg]amix=inputs=2:duration=first[a]" -map 0:v -map "[a]" -c:v copy out.mp4
ใส่โลโก้มุมขวาบนffmpeg -i in.mp4 -i logo.png -filter_complex "overlay=W-w-30:30" out.mp4
เร่งความเร็ว 1.5 เท่าffmpeg -i in.mp4 -vf "setpts=PTS/1.5" -af "atempo=1.5" fast.mp4
บีบไฟล์ให้เล็กลงffmpeg -i in.mp4 -c:v libx264 -crf 28 -preset slow -c:a aac small.mp4
ดึงเสียงออกเป็น mp3ffmpeg -i in.mp4 -vn -q:a 2 audio.mp3
ทำ GIF จาก 5 วินาทีแรกffmpeg -t 5 -i in.mp4 -vf "fps=12,scale=480:-1" out.gif
💡 ทำทีละหลายไฟล์ (Batch)"แปลงทุกไฟล์ .mov ในโฟลเดอร์นี้เป็น .mp4 แนวตั้ง 1080x1920 ใส่ใน output/" Claude จะเขียน loop ทำให้ครบทุกไฟล์

6ซับไตเติลภาษาไทยอัตโนมัติ

  1. ถอดเสียงเป็นไฟล์ .srt
    whisper talk.mp4 --language th --model medium --output_format srt
    ใช้โมเดล medium หรือ large เพราะแม่นกับภาษาไทยกว่า แต่จะช้ากว่า
  2. ให้ Claude ตรวจและแก้ซับ
    "ตรวจไฟล์ talk.srt แก้คำผิด ตัดบรรทัดไม่ให้เกิน 2 บรรทัดต่อซับ ชื่อเฉพาะคือ ___"
  3. ฝังซับลงวิดีโอ
    ffmpeg -i talk.mp4 -vf "subtitles=talk.srt:force_style='FontName=Sarabun,FontSize=22,Outline=2'" talk_sub.mp4
⚠️ ซับไทยขึ้นเป็นสี่เหลี่ยม □□□เกิดจากเครื่องยังไม่มีฟอนต์ไทยที่ระบุไว้ ให้ติดตั้งฟอนต์ Sarabun ลงเครื่องก่อน และใส่ชื่อฟอนต์ใน FontName ให้ตรงกับชื่อที่ติดตั้ง

9เขียน Prompt สำหรับวิดีโอ AI (Veo, Runway, Kling, Sora)

1 ช็อต/มุมกล้อง 2 ตัวละคร/วัตถุ 3 การกระทำ 4 ฉาก/สถานที่ 5 แสง/บรรยากาศ 6 สไตล์ภาพ 7 การเคลื่อนกล้อง

Medium close-up shot of a young Thai teacher smiling while writing on a whiteboard
in a bright modern classroom, soft morning sunlight through the windows,
warm and friendly atmosphere, cinematic, shallow depth of field,
slow dolly-in camera movement, 8 seconds, 16:9

tracking shotกล้องเคลื่อนตามตัวละคร
aerial / drone shotมุมสูงจากโดรน
static shotกล้องอยู่นิ่ง
📋 Prompt ให้ Claude เขียน prompt วิดีโอ AI ให้
ผมจะทำคลิปโฆษณา 30 วิ เรื่อง [หัวข้อ] ด้วย [Veo/Kling/Runway]
ช่วยแบ่งเป็น 4 ช็อต ช็อตละ 6–8 วิ
แต่ละช็อตให้เขียน prompt ภาษาอังกฤษตามสูตร (ช็อต, ตัวละคร, การกระทำ, ฉาก, แสง, สไตล์, การเคลื่อนกล้อง)
ให้ตัวละครและโทนสีเหมือนกันทุกช็อต และทำตารางสตอรีบอร์ดภาษาไทยกำกับไว้ด้วย
🎯 ให้ภาพแต่ละช็อตดูต่อเนื่องกันบรรยายตัวละครด้วยคำเดิมทุกช็อต (เช่น "a young Thai woman in a navy blazer") ถ้าเครื่องมือรองรับภาพอ้างอิง (reference image) ให้ใส่ด้วย เสร็จแล้วนำคลิปที่ได้มาต่อด้วย FFmpeg พร้อมใส่เสียงพากย์และซับ

ทำเสียงพากย์แต่ละฉากจาก script.md ด้วย edge-tts เสียง th-TH-NiwatNeural
